# Architecture view — requirements

## FR-UI-4 Architecture view

- **FR-UI-4.1** **Group problems into problem domains** (create, rename, merge/split as methodology allows).
- **FR-UI-4.2** Define **dependencies** between domains and **contracts** at boundaries (consumer-driven).
- **FR-UI-4.3** Graph or diagram shows domains, cross-domain links, and contracts.
- **FR-UI-4.4** **Select a domain** and request **creation of a specification** for that domain.

Domain model: [../shared/specification.md](../shared/specification.md). Entry to Specification lifecycle: rule C4 in shared spec.
