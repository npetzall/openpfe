# Dashboard — requirements

## FR-UI-2 Dashboard

- **FR-UI-2.1** Summarise counts or status for: problems (open vs handled), specifications (unhandled vs approved), tasks (unhandled vs completed).
- **FR-UI-2.2** Provide entry points into the view where each category is managed.
- **FR-UI-2.3** Surface enough context to answer “what needs attention next?” without opening every view.
