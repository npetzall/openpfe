# Dashboard — specification

**Inputs (conceptual):** aggregates for problems, specifications, tasks.

## Layout (minimum)

- Summary cards or rows: unhandled problems, handled problems, unhandled specifications, approved specifications, unhandled tasks, completed tasks.
- Short “next actions” from non-zero unhandled counts (e.g. “3 specifications await approval”).

## Actions

| Action | Outcome |
|--------|---------|
| **Navigate** | Open target view; apply unhandled filter where possible |
