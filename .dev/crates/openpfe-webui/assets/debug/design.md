**Panels:**

1. **Local LLM** — free-form chat; show active model read-only (link to [Configuration](../configuration/) for download/selection).

Same collaboration channels as [Problem](../problem/) but **without** requiring a selected graph node for LLM; MCP here is for integration testing, not daily handoff.
