# Problem view — design

**Primary question:** What problems exist and how do we refine them?

**Panels (conceptual):**

1. **List** — unhandled problems (default).
2. **Graph** — problems and relationships; selection syncs with list.
3. **Detail / work** — when a problem is selected.

**Collaboration:**

| Mode | Use |
|------|-----|
| **Embedded LLM** | Scoped to selected problem; fast iteration in browser |
| **MCP handoff** | Command/snippet for IDE agent; context shield via MCP |

Marking **handled** removes the problem from the default list; does not require assignment to a domain.
