# Problem view — requirements

## FR-UI-3 Problem view

- **FR-UI-3.1** List problems that are **not** handled.
- **FR-UI-3.2** Show a **graph** of problems (relationships visible; drill-down aligned with PFE fishbone-style exploration).
- **FR-UI-3.3** User can **select** a problem and work on it in-context.
- **FR-UI-3.4** For a selected problem, support **embedded local LLM** (refine, decompose, draft sub-problems).
- **FR-UI-3.5** User can obtain a **command or instruction** to delegate work to **external agentic AI** via **MCP**.
- **FR-UI-3.6** User can mark a problem as **handled**.
