# Domain concepts

Shared vocabulary for all views. Normative states: [specification.md](./specification.md).

| Concept | Meaning (product) |
|---------|-------------------|
| **Problem** | Atomic unit in the problem graph; may be drill-down expanded. |
| **Handled problem** | Problem finished in the Problem view (no longer “open” there). |
| **Problem domain** | Group of related problems (architecture cluster); boundary for dependencies and contracts. |
| **Specification** | Description for a problem domain (or derived scope); drives implementation work once approved. |
| **Unhandled specification** | Specification that lacks review/approval. |
| **Task** | Work item created when a specification is approved. |
| **Unhandled task** | Task not yet completed. |
| **Completed task** | Task marked done. |
