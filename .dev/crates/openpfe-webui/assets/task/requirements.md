# Task view — requirements

## FR-UI-6 Task view

- **FR-UI-6.1** List **unhandled** tasks.
- **FR-UI-6.2** Inspect task detail (linked specification, domain, problems as available).
- **FR-UI-6.3** Mark a task **completed** (updates Dashboard).

Tasks originate from approved specifications (rule C3): [../shared/specification.md](../shared/specification.md).
