# OpenPFE drill — differentiation extras

Sibling of **`SKILL.md`**.

## Default (stay in `SKILL.md`)

**Differentiation** is about **candidate / draft children** you are about to write as **`C/<NN>/problem.md`**: they must be distinct from **each other** (within-batch) and from **existing children** (siblings under the same input), using **`problems["NN"]`** and each **child’s** **`## Summary`**.

## When to read this file

**Rare:** a **draft child** reads like a restatement of **`../problem.md`** (the **ancestor** of **the input**—one level up), not like a **new fork under the current node**. Then you **may** use the same overlap question (“How is this different from …?”) against **`../problem.md`**, with the same semantics as sibling checks in **`SKILL.md`** (**Differentiation**).

Do **not** treat **`../problem.md`** as the primary comparison surface; the primary surface is **existing child** nodes under **the input**.
