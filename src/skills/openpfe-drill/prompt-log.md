# OpenPFE drill — user input log (`prompt.md`)

Sibling of **`SKILL.md`**. **Read this file** when the user or project asks for drill-session logging beside the input **`problem.md`**.

## When to use

Append-only **`prompt.md`** in the **same directory** as the input **`problem.md`**, only if the user or project wants logging.

## Contract

- Append-only; user-authored drill-relevant text only.
- Optional **`# User inputs`** header on first create.
- Use **`---`** and/or dated headings between sessions.
- Not a substitute for **`problems`** or differentiation in **`problem.md`**.
